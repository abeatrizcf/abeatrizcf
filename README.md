## 🔍 Minha abordagem em QA

A qualidade de software vai além de verificar se uma funcionalidade funciona: envolve investigar comportamentos, antecipar cenários e garantir que os requisitos sejam atendidos.

- **Testes funcionais e exploratórios:** investigação do comportamento das aplicações.
- **Testes de regressão:** verificação de funcionalidades após alterações.
- **Automação de testes:** criação e organização de testes com Playwright.
- **BDD e Gherkin:** especificação de cenários a partir do comportamento esperado.
- **Documentação de defeitos:** registro de passos para reprodução e evidências.
- **IA aplicada a QA:** exploração de ferramentas de IA para apoiar a elaboração de cenários e casos de teste.
